GitHub Profile Searcher

Live Website

https://github-profile-searcher-six.vercel.app

Description

A web-based GitHub Profile Searcher that allows users to search for GitHub users and view their profile information and recent repositories.

Features

Search GitHub users by username

Display GitHub profile picture

Display username and bio

Display follower count

Display recent repositories

Repository links open directly on GitHub

FastAPI backend

GitHub API integration

Responsive and professional interface

Technologies Used

HTML

CSS

JavaScript

Python

FastAPI

GitHub API

How It Works

The frontend sends the GitHub username to the FastAPI backend. The backend communicates with the GitHub API and returns the user's profile and repository information to the frontend.
